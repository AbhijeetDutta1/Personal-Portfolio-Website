# Portfolio-Website

Title: Personal Portfolio Website with Integrated Chess Engine

Description:
This project combines a personal portfolio website with a fully playable chess engine, demonstrating both web development and AI integration skills. The repository consists of two main components:

Personal Portfolio Website
Modern, responsive frontend built with HTML, CSS, and JavaScript (Chessboard.js + Chess.js).
Includes sections to showcase projects, skills, and contact information.
Interactive elements, including a playable chessboard connected to the backend engine.

Chess Engine Integration

- High-performance C++ chess engine enhanced with a Python neural network for position evaluation.
- Implements standard chess rules, move generation, and evaluation.
- Integrated with the website backend to allow real-time gameplay directly in the browser.

Key Features:

- Fully functional personal portfolio showcasing skills and projects
- Playable chessboard with drag-and-drop pieces
- Real-time engine moves powered by C++ + Python neural network
- Modular design separating frontend, backend, and engine logic
- Compatible with modern web hosting platforms (frontend static hosting + backend server)

Tech Stack:
- Frontend: HTML, CSS, JavaScript
- Backend API: Python (Flask or FastAPI)
- Engine: C++ chess engine + Python neural network

Hosting: Frontend on GitHub Pages / Vercel, Backend on Render / Railway

Usage:

- Host the backend engine server locally or on a server.
- Open the portfolio website in a browser.
- Drag and drop chess pieces; the engine responds automatically.

Future Enhancements:

- Improved AI strength targeting ~2000 Elo
- Additional interactive portfolio features (project demos, analytics)
- Mobile-friendly responsive design
- Training tools for neural network improvements
